PATCH /v1/databases/{databaseId} · Solo consola

Solo consola: este endpoint necesita la sesión de un usuario identificado en la consola. Api-Key y Api-Secret no funcionan con él, y no hay una forma admitida de llamarlo desde tu código. Se documenta para explicar lo que hace la consola. La consola lo hace por ti en API keys & settings → General.

Campo del cuerpo Tipo Significado
name string Nombre nuevo. El id no cambia.

Cuerpo de la petición:

1{"name": "my-app-prod"}
