处理数据

插入、读取、更新和删除文档。

开始之前： 本指南使用 快速开始 留下的 customers 集合（包含 Ada 和 Grace）及其环境变量。它会添加两个标记为 "trial": true 的临时客户，并在最后删除它们，因此 customers 会恢复原样。

插入文档

插入使用 JSON Lines（JSONL）：每行一个 JSON 对象。一个请求可以包含一个文档，也可以包含数百万个。

curl -X POST "https://inceptiondb.hola.cloud/v1/databases/$INCEPTIONDB_DATABASE/collections/customers:insert" \
  -H "Api-Key: $INCEPTIONDB_API_KEY" \
  -H "Api-Secret: $INCEPTIONDB_API_SECRET" \
  -H "Content-Type: application/x-ndjson" \
  --data-binary '{"id":"linus","name":"Linus Torvalds","plan":"free","country":"FI","mrr":0,"trial":true}
{"id":"barbara","name":"Barbara Liskov","plan":"team","country":"US","mrr":300,"trial":true}'

	"fmt"
	"io"
	"net/http"
	"os"
	"strings"
)

func main() {
	body := "{\"id\":\"linus\",\"name\":\"Linus Torvalds\",\"plan\":\"free\",\"country\":\"FI\",\"mrr\":0,\"trial\":true}\n{\"id\":\"barbara\",\"name\":\"Barbara Liskov\",\"plan\":\"team\",\"country\":\"US\",\"mrr\":300,\"trial\":true}"

	if err != nil {
		panic(err)
	}

		panic(err)

	responseBody, err := io.ReadAll(resp.Body)
	if err != nil {
		panic(err)
	}

	fmt.Println(string(responseBody))
}

响应（201 Created）返回已保存的文档，其中已应用集合的默认值：

1{"id":"linus","name":"Linus Torvalds","plan":"free","country":"FI","mrr":0,"trial":true}
2{"id":"barbara","name":"Barbara Liskov","plan":"team","country":"US","mrr":300,"trial":true}

JSON 数组不是 JSONL。这个请求体会以 400 Bad Request 被拒绝，消息为 document must be a JSON object：

1[{"id":"linus"},{"id":"barbara"}]

同样的两个文档，使用 JSONL：

1{"id":"linus"}
2{"id":"barbara"}

注意：

  • 没有 id 的文档会从集合的 默认值 获得一个（除非你修改，否则是随机 UUID）。
  • InceptionDB 不检查 id 是否唯一：用同一个 id 插入两次会保存两个文档。要避免这种情况，请在 id 上创建 map 索引。之后重复的 id 会返回 409 Conflict，按 id 读取也会立即完成。
  • 文档按顺序保存，插入会在第一个被拒绝的文档处停止。之前的文档仍会保存。
  • 要加载文件，使用 --data-binary @customers.jsonl。-d 会去掉换行符。
  • 每个文档必须是没有重复字段名的 JSON 对象，否则返回 400 Bad Request。
  • 如果 唯一索引 中已存在该值，返回 409 Conflict。
  • 向不存在的集合插入会创建该集合。请检查 URL 中的集合名称。

更新文档

patch 只修改你发送的字段（JSON merge patch）：新字段会被添加，已有字段会被替换，null 会删除字段。

curl -X POST "https://inceptiondb.hola.cloud/v1/databases/$INCEPTIONDB_DATABASE/collections/customers:patch" \
  -H "Api-Key: $INCEPTIONDB_API_KEY" \
  -H "Api-Secret: $INCEPTIONDB_API_SECRET" \
  -H "Content-Type: application/json" \
  -d '{"filter": {"id": "linus"}, "patch": {"plan": "pro", "mrr": 49, "country": null}}'

"limit": -1 表示所有匹配的文档。没有任何匹配时，返回 204 No Content。

patch 也可以修改文档的 id。如果集合在 id 上有 map 索引，改成已存在的 id 的 patch 不会被应用。
